# Kaptal 📊

Application Android de gestion financière personnelle construite avec **Jetpack Compose**, **Kotlin** et **Firebase**.

## 🛠️ Stack Technique
* **Interface :** Jetpack Compose (Material 3)
* **Architecture :** MVVM (ViewModel, StateFlow/State)
* **Backend & Auth :** Firebase Authentication & Cloud Firestore
* **Langage :** Kotlin
